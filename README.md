# 紙間 Paper Between

把散落的知識，收進一本好讀的筆記。

紙間是使用 Vue 3、TypeScript 與 Vite 製作的純前端翻頁筆記本。桌機採左右雙頁，窄螢幕切換單頁；內容會依瀏覽器實際排版高度自動分頁。

## 功能

- 多本書架：新增、切換、重新命名、複製、回收桶與還原。
- Word `.docx` 匯入，或直接輸入／貼上文字；預設建立新本，可追加至目前筆記。
- 保留標題、段落、粗體、清單、換行與基本表格。
- DOM 量測分頁、3D 翻頁、鍵盤／觸控操作、直接跳頁與全文搜尋。
- IndexedDB 保存每本內容與閱讀位置，並提供 JSON 書架備份匯出／匯入。
- 奶油白、暖灰、沙色與可可棕的大地配色。

## 本機啟動

需要符合 Vite 8 要求的 Node.js，例如 Node.js 22.12 以上的 22 系列。

```sh
npm ci
npm run dev
```

開啟終端機顯示的網址，預設為 `http://127.0.0.1:5178/`。

Windows 也可以執行 `start-notebook.cmd`。

```sh
npm run build
npm run preview
```

`build` 包含 TypeScript 檢查；正式靜態檔案輸出到 `dist/`。請透過 HTTP 伺服器開啟，不要直接雙擊 `dist/index.html`。

## 資料與限制

文件只在瀏覽器內解析及保存，不會上傳至 GitHub 或網站伺服器。不同網址、瀏覽器或裝置各自儲存；從本機搬到線上版時，請先在原網址下載書架備份，再到新網址匯入。

- Word 上限 10MB；圖片、文字方塊與複雜版面尚不支援。
- PDF 匯入、圖片筆記與持久螢光筆標註尚未實作；搜尋命中會暫時標示。
- 尚未提供雲端同步、協作或版本歷史。請定期下載書架備份。
- 備份單檔上限 50MB，還原最多 500 本。
- 已用 Chrome 驗證手機尺寸與桌機畫面；實體手機與 Safari 尚未驗證。

## 架構

`src/core/` 分別處理文件正規化、匯入、自動分頁、搜尋、閱讀位置、書架、儲存及備份。`src/components/` 包含紙頁、翻頁書本、書架及編輯介面。Word 解析在 Web Worker 進行。

第三方套件授權會在建置時彙整到 `dist/third-party-notices.txt`。測試程式目前留在本機工作區，未隨此 repository 發布。
