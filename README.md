# 頁白

把散落的知識，收進一本好讀的筆記。

頁白是使用 Vue 3、TypeScript 與 Vite 製作的純前端翻頁筆記本。桌機採左右雙頁，窄螢幕切換單頁；內容會依瀏覽器實際排版高度自動分頁。

## 功能

- 首次使用為空白書架，自行匯入 PDF、Word 或書架備份，也可新增圖文／貼上文字；不預載任何範例或私人文件。
- 多本書架：新增、切換、重新命名、複製、回收桶與還原。
- 書卡操作採 Lucide 圖示；桌機移入／鍵盤聚焦顯示中文浮動標籤，支援 Esc 關閉與視窗避讓。觸控裝置保留圖示下方的小字，匯入備份也有獨立圖示。
- Word `.docx` 匯入，或直接輸入／貼上文字；預設建立新本，可追加至目前筆記。
- 保留標題、段落、粗體、清單、換行與基本表格。
- DOM 量測分頁、3D 翻頁、鍵盤／觸控操作、直接跳頁與全文搜尋。
- IndexedDB 保存每本內容與閱讀位置，提供含圖片與重點的 ZIP 書架備份，亦可還原舊版 JSON。
- 圖文編輯器可持續加入多組圖文、貼上截圖，切換左右／上下排列。
- 選取文字畫螢光筆，依重點、定義、疑問、待辦分類，可加標籤與心得、跨本搜尋及回到原文。
- 奶油白、暖灰、沙色與可可棕的大地配色。
- 太陽／月亮切換白天與夜間；白天米白紙，夜間暖深灰紙與可可色桌面。首次跟隨系統，手動選擇會記住；完整 ZIP 備份也帶入模式偏好。
- 圖文輸入區有操作引導、醒目的對應文字框及每組右上角 X。小圖不放大，大圖依欄寬／頁面限高等比縮小，圖片與圖說置中、不補底色、不裁掉內容；手機採上下排列。

## 本機啟動

需要 Node.js 22.13 以上的 22 系列（符合 Vite 與 PDF.js 要求）。

```sh
npm ci
npm run dev
```

開啟終端機顯示的網址，預設為 `http://127.0.0.1:5178/`。

Windows 也可以執行 `start-notebook.cmd`。

```sh
npm run build
npm run preview
```

`build` 包含 TypeScript 檢查；正式靜態檔案輸出到 `dist/`。請透過 HTTP 伺服器開啟，不要直接雙擊 `dist/index.html`。

## 資料與限制

文件只在瀏覽器內解析及保存，不會上傳至 GitHub 或網站伺服器。不同網址、瀏覽器或裝置各自儲存；從本機搬到線上版時，請先在原網址下載書架備份，再到新網址匯入。

1.4.2 起品牌更名為「頁白」。既有網址、瀏覽器儲存識別與備份格式維持相容，原有筆記、閱讀進度、模式偏好及舊版備份可繼續使用。

圖片與 PDF 原貌頁面保留原始顏色，夜間模式不會反相圖片或改寫 PDF。模式偏好只用小型 localStorage 設定，文件與圖片仍使用 IndexedDB。

舊版未修改、未改名、未標記的內建示範會自動移除；已編輯或註記的筆記保留。`src/data/demo.ts` 是原先依需求手寫的示範來源，現在僅作本機測試資料，不會由網站載入或打包，並非來自使用者的 PDF。

- Word 上限 10MB，保留內嵌圖片；文字方塊與複雜版面會提示略過。
- PNG/JPEG/WebP 單張原檔上限 10MB、24 百萬像素；自動縮至長邊 2000px、每張 2MB 以下。每本最多 50 張、媒體合計 50MB。
- PDF 原貌匯入保留圖片與文字層，支援搜尋、選字、重點與放大閱讀（最高 300%）；上限 10MB、200 頁。
- PDF 掃描頁可顯示圖片，但沒有文字層時不能搜尋或選字；尚未提供 OCR。PDF 原文不可直接改寫，請另建圖文筆記。
- 原文編輯後會依區塊、文字位置與摘錄內容重新連結重點；無法唯一定位的摘錄仍保留，並標示為待重新標記。
- 尚未提供雲端同步、協作或版本歷史。請定期下載書架備份。
- ZIP 備份媒體合計上限 100MB，匯入 ZIP 上限 110MB，還原最多 500 本。大型書架可用書卡上的「備份此本」分批保存。
- 已用 Chrome 驗證手機尺寸與桌機畫面；實體手機與 Safari 尚未驗證。

## 架構

`src/core/` 分別處理文件正規化、匯入、自動分頁、搜尋、閱讀位置、書架、儲存及備份。`src/components/` 包含紙頁、翻頁書本、書架及編輯介面。Word 解析在 Web Worker 進行。

第三方套件授權會在建置時彙整到 `dist/third-party-notices.txt`。測試程式目前留在本機工作區，未隨此 repository 發布。
