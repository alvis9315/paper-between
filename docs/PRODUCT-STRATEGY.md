# 頁白｜產品定位、競品與後續方向

記錄日期：2026-11-06（Asia/Taipei）。本文件保存使用者要求保留的產品建議，**是待驗證方向，不是已完成的功能或市場結論**。實際功能與開發進度以 STATUS、CHANGELOG 為準。

## 定位假設

「把資料變成漂亮筆記」容易被通用 AI 與既有工具取代。頁白可先聚焦：**把難讀的講義，變成隨手能讀、隨時能練的考前書**。

從使用者的教材推導，第一個待驗證族群是使用繁體中文、圖表密集、小字很多的課程與證照講義的人。書本質感吸引開始使用；匯入可靠、手機可讀、校正省事、來源查證與跨裝置接續支撐持續使用。不要為了書本外觀縮小文字或破壞原有內容關係。

## 建議的產品優化

1. **首次價值**：匯入後立即改善手機閱讀；保留圖解、放大正文、辨識主題並方便校正。以真實教材前後對照展示，再試三張卡。首次整理不可比原文件更難讀。
2. **同一內容的多種使用方式**：在書裡選重點建卡，卡片能回到原頁／原區域，校正的說明持續保留。書本供完整閱讀，單卡供零碎複習。
3. **從展示卡到練習卡**：增加先回想再揭答案的問答、圖解遮蔽、易混觀念比較及不熟／易錯內容。搜尋與主題組成相關卡組，保留滑動與直接跳選。看過張數不能冒充掌握程度。
4. **可靠保存與跨裝置接續**：保留免登入本機使用，評估可選同步、自動保存與還原。電腦整理、手機複習不應依賴反覆手動 ZIP 搬移。
5. **明確可完成的任務**：考試日期、範圍、每天可用時間；提供五分鐘複習、上次不熟、指定主題等入口。完成回饋依實際回答／復測，避免僅用瀏覽量或連續登入營造進步。

長期價值來自使用者校正內容、個人易錯點、教材與卡片關係及可接續的進度；資料仍應完整可匯出。可把 GPT／Claude 整理結果視為未來的 Markdown／結構化內容入口，由頁白承接閱讀、保存與複習，尚未完整實作此匯入能力。

## 建議順序與驗證

可靠匯入與保存 → 跨裝置接續 → 圖文重排與精確原文定位 → 問答／遮圖練習 → 考前安排。這是方向排序，實際先處理阻斷閱讀的錯誤。

找 5–10 位正在準備考試的人，以自己的教材試用兩週，記錄：

- 從匯入到有效閱讀所需時間、錯誤與人工校正量；與原 PDF、通用 AI 及直接競品用相同教材比較。
- 是否主動帶入第二份教材。
- 是否在手機回來閱讀／複習，哪些步驟使其放棄。
- 考試週內回訪與下一科／下次考試是否再次選用；考前產品有週期，不只用每日活躍判斷價值。

## 目前基礎與缺口（1.7.0）

已有雙頁／單頁閱讀、搜尋、重點、小卡、可校正的圖文重排第一階段與 ZIP 保存。小卡主要是原文分段，沒有完整問答揭示、間隔複習、考試排程或自動同步；來源回到書本，尚未精確定位到原頁／原區域。重排未提供 OCR、彩色區塊自動拆解或圖解節點重建。

使用者本輪回報 PDF 還原成 Word 後匯入版面崩壞；此為最高優先修正。固定座標文字方塊不能直接當一般段落攤平。不可在基本匯入仍破壞內容時，先擴大更多複習功能。
