# 考前小卡

與書架並列的獨立區塊。1.8.0 依使用者指定的 AppsScript HTML 參考重做：桌機左側選題、右側讀卡；手機在結果清單與單卡之間切換，維持單張閱讀。

## 介面與操作

- 小卡左右邊界與頁白頂部品牌使用同一份 `--workspace-gutter`，移除 1100px 限寬及第二層側邊距。主畫面只留搜尋、操作、來源／收藏、主題與卡片，說明放進小卡使用說明。
- **桌機 >900px**：左邊常駐搜尋結果，右邊完整卡片，各自捲動；點題目直接切卡。
- **手機 ≤900px**：上方搜尋獨立保留，其餘操作進選單；搜尋、主題、來源、收藏改變時先看相關結果，點題目後收起鍵盤並讀卡。清單入口與「回卡片」可來回切換。
- 搜尋涵蓋標題、完整內容、速答、題幹、章節、來源、標籤與別名；支援多關鍵字、大小寫、全半形與分隔符號正規化。標題／主題／速答命中的結果優先；呈現能直接對應的關鍵字高亮。
- 主題、來源與收藏可以一起篩選；全部標籤面板另有原章節入口。第一次顯示 60 個結果，可分批展開，卡片不受這個呈現上限限制。
- 卡片有可選速答、題幹、完整答案、表格與題圖；題圖可在主題視窗放大，表格在自身區域左右捲動，不觸發換卡。
- 星號收藏進卡片資料；字級 17／19／21px 與上次閱讀卡片記在 `paper-between-card-view`。字級與位置偏好仍屬目前瀏覽器，收藏隨 ZIP 保存。
- 方向鍵、前後按鈕與手機橫滑切換目前結果組；相關小卡可清除篩選後直接跳到另一張。選字、長按與多指手勢不當成換卡。
- 頁白維持原日夜主題；搜尋輸入至少 16px、保留手動縮放，小卡工作區沿用 visualViewport 可見高度。所有捲軸仍只在實際捲動時顯示。

## 建立與編輯

- 「新增小卡」填標題、內容、標籤與可選速答。
- 「從筆記建立」可用全文或重點摘錄，也能從該面板匯入 PDF／Word；原文件保留在書架。
- Word 標題 1／2 作主題，較細標題作卡片標題；無可靠標題則使用書名。PDF／固定原頁 Word 按原頁文字拆分，保留原頁文字對照，主題先用書名。可先使用圖文重排校正主題／圖解，再建卡。
- 原文拆卡沒有 AI 摘要、出題或答案推導。使用者提供的結構化速答／答案直接保留；不要把這輪說成已提供 AI 自動整理、問答揭示或間隔複習。
- 既有卡片可修改、刪除。只改標題／標籤／速答保留 rich HTML；修改完整內容會改成文字排版，編輯視窗有提醒。原始來源文字仍保留作對照。

## 匯入使用者的小卡 HTML／JSON

在空白頁按「匯入小卡」，或從工具列／手機選單選「匯入小卡 HTML／JSON」，選擇檔案。使用者的 `企業網路考前小卡_AppsScript/index.html` 可直接匯入，不需要執行 AppsScript 或另外部署。

支援含以下 JSON 區塊的 HTML：

- `cards-data`：卡片陣列，包含 id、title、tags、answerHtml，並可有 summary、context、kind、section、keywords、source、pages、imageKey。
- `sources-data`：來源識別 → 按原頁順序排列的文字陣列。
- `images-data`：圖片識別 → 內嵌 PNG／JPEG／WebP data URL。

也支援 `{ cards, sources, images }` 的 JSON；不是任意網頁擷取器。只讀資料，不執行匯入 HTML 的 script。答案以白名單清理，保留表格、清單、粗體、上／下標等；不保留事件、外部圖片或程式。原文與圖片不會上傳伺服器、放進 GitHub 或預載給其他訪客。

匯入前驗證整組卡片與參照，錯誤用主題彈窗說明並保留現有資料。內容指紋避免相同檔案重複加入；重新選相同檔案不覆蓋人工修改／收藏。來源變更的檔案會視為新資料。

HTML 附的「原文對照」是該頁抽取文字，**不是原 PDF 視覺檔案**；原圖表版面仍以使用者原檔為準。從書架建卡且來源仍存在時，另提供回到來源筆記。

## 資料與備份

- `ReviewCard` 沿用 IndexedDB `library-index.reviewCards`，不需要先有書本；純小卡書架可以保存及完整 ZIP 搬移。
- 1.8.0 新增可選 favorite、summary、context、answerHtml、section、kind、keywords、sourcePages；舊卡／舊備份沒有這些欄位仍可讀。
- 完整 ZIP 保存答案格式、速答、收藏、原頁文字與題圖。還原先完整驗證，再加入；本機書本來源 ID 會重映射，HTML 來源指紋保留。
- 同一來源內容去重，不覆蓋已人工編輯的卡；來源文字改變可能產生新卡。
- 每個瀏覽器最多 2000 張，標題 160 字、內容 6000 字、8 個標籤各 60 字；匯入檔上限 10MB。額外速答 500 字、題幹 4000 字、答案 HTML 40000 字、別名最多 80 個各 120 字；來源對照每卡最多 20 頁、每頁 30000 字、合計 200000 字。超長 PDF 頁保留清楚標記的原文片段並可回來源。
- 題圖沿用既有媒體壓縮／像素上限，仍須備份。沒有跨裝置自動同步。

## 開發入口與驗證

- `components/StudyCards.vue`、`study.css`：響應式選題／閱讀、搜尋、標籤、來源／收藏、字級、滑動與對話框。
- `core/cardImport.ts`：只讀資料的 HTML／JSON 匯入、參照驗證、媒體與去重識別。
- `core/cardContent.ts`：答案白名單、原文、正規化搜尋、文字節點高亮及新欄位驗證。
- `core/reviewCards.ts`：原筆記／重點拆卡及還原；`storage.ts`／`backupBundle.ts` 沿用共同保存與媒體保留。
- `tests/study.spec.ts` 與 `tests/study-layout.spec.ts`：合成資料驗證兩套版面、來源／主題／搜尋／收藏交集、別名／全半形、字級／位置、圖片、原文、表格不換卡、手機輸入與窄視窗、重複及錯誤匯入、程式不執行、ZIP 完整還原。
