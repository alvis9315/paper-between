# 考前小卡

1.7.0 起，與「我的書架」並列的獨立資料區塊。電腦與手機皆一次閱讀一張，小卡使用獨立卡面，不沿用雙頁書本。

## 使用方式

- 上方「考前小卡」進入；新增可自行填寫標題、內容與主題標籤。
- 「從筆記建立」可選完整內容或重點摘錄；也能匯入 PDF／Word，原文件仍存書架。
- Word 的標題 1／2 會成為主題標籤，較細標題作為卡片標題；無可靠標題時使用筆記名稱。長標籤最多 60 字，完整標題仍在卡面。
- PDF 原頁沒有可靠段落結構，直接建卡時按原頁文字拆分，主題先用檔名。可先用「圖文重排」確認圖解、閱讀順序與主題，再建立小卡。
- 上方標籤按鈕篩選一組卡片，搜尋同時涵蓋標題、內容、來源與標籤；多個關鍵字都需命中。搜尋與主題可以並用。
- 仍一次看一張，頁數顯示目前／結果總數；左右箭頭、方向鍵或手機橫向滑動依序切換這組結果。
- 搜尋旁清單顯示相關卡片摘要，點選直接跳到該張；先顯示 60 張，可展開更多。
- 可修改標題、主題與內容，或移除小卡；原筆記不跟著刪除。來源可用時能直接回去閱讀。

小卡保留原文並分段，不是 AI 自動摘要，也不會自行補寫考試答案。可在使用前校正內容。原始 PDF 中沒有文字層的部分，尚未提供 OCR。

## 資料與備份

- `ReviewCard` 存在既有 IndexedDB `library-index.reviewCards`，與書架共用一次原子儲存，但不必先有書本；純自建小卡書架也可保存及備份。
- 相同來源內容以 sourceKey 去重，重新建立不覆蓋已人工編輯的小卡；來源內容變動後可能產生新卡。
- 圖文來源可把圖解與緊接的說明放在同一張卡，沿用媒體資產；圖片較多或內容較長時卡面內部可捲動。
- 完整 ZIP 包含小卡、圖解、來源筆記、閱讀位置等；單本備份只含對應來源的小卡。舊 ZIP／JSON 沒有小卡欄位仍可匯入。
- 還原會建立新 ID 並對應新來源筆記；完整檢查後才加入。損壞的小卡或缺圖不會部分加入或覆蓋現有資料。
- 每個瀏覽器最多 2000 張，小卡內容最多 6000 字、標題 160 字、8 個標籤（各 60 字）。沒有跨裝置自動同步；換裝置使用完整 ZIP。

## 開發入口與驗證

`src/components/StudyCards.vue`：單卡、搜尋、標籤、結果清單、滑動與編輯。

`src/core/reviewCards.ts`：從標題／段落／圖文／摘錄建卡、長文切分及備份驗證。

`src/core/storage.ts`：小卡索引、媒體保留；`backupBundle.ts`：小卡與來源 ID／媒體的 ZIP 還原。

`tests/study.spec.ts`：主題關聯、結果跳轉、修改與去重、純小卡保存、圖解重排後建卡、圖片保存、直接匯入、錯誤備份及大量相關結果。跨 Chrome／WebKit，自動化不等同實體 Safari 26.0.1 驗收。
